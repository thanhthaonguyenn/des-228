positioning elements

Static

default, as-is behavior

Relative

this positions a child relative to its parent. by giving an element a relative position, we can place it outside the normal flow of where it would be- but it still impacts other elements

Absolute

this takes the element out of the line up and no longer impacts elements around it, BUT you have to apply position:relative to a parent container

Fixed

positioned in relation to the browser window, it just stays put!

***Sticky***

this one is a little more advanced, and we won’t get into it yet, but perhaps challenge yourself and your project to see if you can figure it out?


Next up: z-index

this is how we control layering when we are using positioning. if an element has a position, you can add a z-index, the larger the number the closer to the top.
0=bottom 100=top
think of z-index like the “bring to front” or “send to back” in design software.

Reflection

In this assignment, I learned how to use different CSS positioning properties to organize elements on a webpage. I think relative positioning was the easiest to understand because I could move elements using top, left, right, and bottom. Absolute positioning was more challenging because the elements moved based on their positioned parent container. I experimented with moving the blue image and four orange circles to different positions. I changed their sizes and adjusted their locations to make the layout look better. I also used z-index to bring the "positioning elements" title in front of the blue image and orange circles. This helped me understand how layering works in CSS. One challenge I had was moving the "footer nav" text without changing the position of the other footer text. I tried adjusting the CSS several times to find the correct position. I also learned that fixed positioning keeps the footer in the same place on the browser window when scrolling. I think positioning will be useful in my Interactive Sketchbook for organizing images, text, and decorative elements. However, using too much positioning can cause overlapping problems, especially on smaller screens. Overall, this assignment helped me better understand CSS layouts and how to experiment with different values.
