Process Reflection

In this lab, I learned how to use Flexbox to create a multi-column layout. At first, I had some trouble understanding the relationship between the parent container and the child containers. I learned that the main content div needs to be the flex container, while the lyrics and album information are the flex items inside it. After adding display: flex and flex-direction: row, I could see the two sections move next to each other instead of appearing vertically.I also experimented with percentages to control the width of each column. I adjusted the padding to create more space around the content and make the page easier to read. I also changed the size of the album image so that it looked more balanced with the lyrics column and closer to the reference layout. One problem I had was that the custom font did not appear at first. I realized that the path to the font file was incorrect, so I corrected the file path in CSS. This lab helped me understand Flexbox better, especially how parent and child elements work together to create a layout.
