About Us

This project helped me understand how CSS can completely change the appearance of a webpage without changing much of the HTML structure. I first focused on matching the reference image by adjusting the page width, background colors, fonts, spacing, and image sizes. Some parts were easier, such as changing colors and fonts, while other parts were more difficult, especially getting the image sizes and spacing to match the example closely. I also learned that small CSS changes can affect several elements at the same time, so I had to check the page often after making edits. One problem I had was that some images were much larger than expected, so I used more specific selectors to control only those images. I also learned more about using Google Fonts and choosing the correct selector for each element. If I had more time, I would continue adjusting the spacing and image proportions so the page matches the reference even more closely.
