What does this mean?
“width=device-width”– width of page is the same as width of viewport
MY WEBSITE ADAPTS TO THE WIDTH OF THE DEVICE
ex: if the viewport is 325px wide, the page will display as 325px wide
“initial-scale=1.0” – page should not zoom in/out when first loaded.

place the gifs side-by-side to compare the difference between fixed/fluid/responsive

fixed – this is us now

fixed layouts rely on a static container with a fixed pixel width. resizing browser has no impact

fluid – we kinda know this

fluid layouts use relative units and the layout increases/decreases with the browser window. layout breaks at small scale

responsive – GOALS

responsive web design is about using HTML and CSS to automatically resize, hide, shrink or enlarge a website to make it look good across all devices.

Reflection

In this lab, I learned how to make a website responsive to different screen sizes. The original layout started to break when I made the browser window smaller because some text and images were too large and did not fit properly. I chose 600px and 400px as my two breakpoints because the layout needed adjustments for smaller screens. At 600px, I changed the Flexbox layout to a single column and adjusted the images and text. At 400px, I reduced the font sizes, logo size, and spacing to make the page easier to read. The easiest part was making images responsive using max-width: 100% and height: auto. The hardest part was adjusting the layout to prevent extra space and content from overflowing on mobile screens. I learned that Flexbox helps organize elements, relative units make sizes more flexible, and media queries allow the design to change depending on the screen width.
